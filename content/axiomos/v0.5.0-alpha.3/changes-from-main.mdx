## What this release contains

- **All code and docs on `main` as of `78600068`** (2026-07-19). The kernel, eBPF subsystem, platform support, userspace, firmware, tests and CI described elsewhere in this section are that snapshot.
- **Two release-only commits**, both documentation:

| Commit | Date | Change |
|---|---|---|
| `36518dfe` | 2026-07-19 | `docs: specify v0.5 runtime evolution`: adds `docs/design/active/v0.5-runtime-evolution.md` and lists it in `docs/design/active/README.md` |
| `0567193e` | 2026-07-20 | `docs: adding design edits`: expands the design document to its final 1,144-line form |

The design document specifies the v0.5 behavior registry, atomic hot-swap, rollback and flight recorder, and names this branch as its implementation contract. **None of it is implemented on this branch.** See [v0.5 Runtime Evolution](/axiomos/v0.5.0-alpha.3/design/v0.5-runtime-evolution).

On `main`, the design document is not present at `docs/design/active/`; `main` instead carries `docs/plans/active/v0.5-runtime-evolution-engineering-draft-v2.md`.
