## Authority order

When documents disagree, the repository resolves them in this order ([system-overview.md](https://github.com/pro-utkarshM/axiomOS/blob/feat/fpga-bringup/docs/architecture/system-overview.md)):

1. Generated authorities under `docs/reference/generated` (ABI, targets, components, artifacts, build inputs, quality).
2. Accepted decisions under `docs/decisions`.
3. Current architecture documents.
4. Source code and its required gate evidence.
5. Archived and legacy documents (historical only).
